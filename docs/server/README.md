# OpsLens Pulse Server

The server receives metrics and heartbeats from agents
and provides a web-based UI for monitoring.

## Features
- Metrics ingestion
- Heartbeat tracking
- Host availability status
- Token authentication
- In-memory data store
- Web UI

## Ports
- Default port: `9898`
