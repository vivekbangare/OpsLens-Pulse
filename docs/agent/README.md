# OpsLens Pulse Agent

The agent runs on target hosts and periodically sends
system metrics and heartbeats to the server.

## Metrics Collected
- CPU usage
- Memory usage
- OS & uptime
- Host IP

## Capabilities
- Configurable interval
- Tag-based metadata
- Cross-platform support
